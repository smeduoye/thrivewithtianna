# Brand naming — Thrive with Tianna

**Status:** Decided (June 2026)

## Summary

| Layer | Name | Use for |
|-------|------|---------|
| **Brand / business** | **Thrive with Tianna** | Logo, domain, product, “Thrive Method”, Instagram handle |
| **Founder (real name)** | **Wumi** | First person, bio, sessions, moderation, quotes, internal docs |
| **Public coaching name** | **Tianna** (pseudonym) | Disclosed as **Tianna, aka Wumi** — not used alone when referring to the person |

## Copy rules

### Use **Thrive with Tianna** (brand)

- Page titles, logo, footer, company name
- Hero headline “Thrive with *Tianna*”
- Program and community name
- Formspree subjects, legal entity trading name

### Use **Wumi** (founder)

- First person: “Hi, I'm Wumi…”
- Direct references: “1:1 sessions with Wumi”, “moderated by Wumi”
- Testimonials about the coach (POC placeholders)
- Image alt text: “Wumi — founder of Thrive with Tianna”
- Quote attribution: “— Wumi”
- Internal specs: “Wumi (founder)” for approvals and coach workflows

### Disclose the pseudonym (public)

Include **Tianna, aka Wumi** at least once on the marketing site (My Story section).

Do **not** use “Tianna” alone when you mean the founder (e.g. avoid “Hi, I'm Tianna”, “sessions with Tianna”).

### Use **your coach** (optional)

Generic warmth without a name: “Optional check-in with your coach”.

### Portal / product voice

**Your Thrive Coach** — AI and async messaging persona (see [`CLIENT_PORTAL_SPEC.md`](./CLIENT_PORTAL_SPEC.md)).

## Examples

| Avoid | Prefer |
|-------|--------|
| Hi, I'm Tianna | Hi, I'm Wumi. *Tianna, aka Wumi*, is my coaching name. |
| Sessions with Tianna | Sessions with Wumi |
| Tianna's coaching | Wumi's coaching |
| Thrive with Wumi (brand) | Thrive with Tianna |
| Hide real name entirely | State pseudonym clearly once in My Story |
